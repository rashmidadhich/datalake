# Bronze Ingestion Assignment Submission

This ZIP contains the completed Stack AI Rewire Bronze Ingestion assignment.

Start in [`starter-code/README.md`](starter-code/README.md). It provides:

- Python, Java, and Windows Hadoop prerequisites
- Fresh virtual-environment setup commands
- The required Batch 1 through Batch 5 execution order
- Commands to inspect every generated Bronze Parquet table and Batch 5
  quarantine output
- The full test command and troubleshooting guidance

Keep these folders together after unzipping:

```text
.claude/        reusable skills used by the implementation
data/           supplied CSV sources and sample batches
starter-code/   source code, tests, Bronze and quarantine outputs, evidence
```

The completed rubric workbook and validation evidence are in
`starter-code/outputs/artifacts/`.
